## 时序图一：对局落子与胜负判定

玩家点击交叉点后，界面把坐标交给 `Game.click`。系统先查空点，黑棋再查禁手，合法则落子并判定连五或满盘。

```mermaid
sequenceDiagram
    autonumber
    actor P as 玩家
    participant UI as MainFrame
    participant Game
    participant Board
    participant Rules as ForbiddenAnalyzer
    participant Store as AppStore

    P->>UI: 点击棋盘交叉点(x,y)
    UI->>Game: click(x,y)
    Game->>Board: isEmpty(x,y)
    Board-->>Game: 空点 / 已占用
    alt 已占用或对局已结束
        Game-->>UI: PlaceResult 拒绝
        UI-->>P: 提示无法落子
    else 空点可落
        opt 黑棋且开启禁手
            Game->>Rules: previewForbidden(board,x,y)
            Rules-->>Game: 无禁手 / 双三双四长连
        end
        alt 命中禁手
            Game-->>UI: PlaceResult 拒绝禁手
            UI-->>P: 提示禁手，棋盘不变
        else 合法落子
            Game->>Board: set(x,y,当前方)
            Game->>Rules: isExactFive / isFiveOrMore
            Rules-->>Game: 是否连五
            alt 连五或满盘
                Game-->>UI: PlaceResult 黑胜 / 白胜 / 和棋
                UI->>UI: 高亮胜线并弹出对局结束
                UI->>Store: recordResult
                Store-->>UI: 更新 Elo
                UI-->>P: 显示终局结果
            else 对局继续
                Game-->>UI: PlaceResult 换手
                UI-->>P: 刷新棋盘，提示对方走子
            end
        end
    end
```

## 时序图二：人机对战

玩家开局并落下一手后，界面调用 AI 选点，再由系统替 AI `commit`。若本轮终局则写 Elo 并弹窗，否则继续等玩家。

```mermaid
sequenceDiagram
    autonumber
    actor P as 玩家
    participant UI as MainFrame
    participant Game
    participant AI as GomokuAi
    participant Rules as ForbiddenAnalyzer
    participant Store as AppStore

    P->>UI: 选择人机对战并设置难度、禁手
    UI->>Game: new Game(PVE)
    Game-->>UI: 新对局，黑棋先行
    UI-->>P: 显示空棋盘

    P->>UI: 点击交叉点落子
    UI->>Game: click(x,y)
    Game->>Rules: 校验空点、禁手、连五
    Rules-->>Game: 合法且未终局
    Game-->>UI: PlaceResult 落子成功，换手
    UI-->>P: 刷新棋盘

    UI->>AI: choose(game)
    AI->>Rules: 评估成五、堵四、冲三
    Rules-->>AI: 候选点分值
    AI-->>UI: 选中坐标
    UI->>Game: commit(aiX,aiY)
    Game->>Rules: 校验并判定胜负
    Rules-->>Game: 连五 / 未终局 / 满盘
    Game-->>UI: PlaceResult

    alt 对局结束
        UI->>Store: recordResult
        Store-->>UI: 写入 Elo 与排行
        UI-->>P: 弹出对局结束
    else 对局未结束
        UI-->>P: 等待玩家继续落子
    end
```

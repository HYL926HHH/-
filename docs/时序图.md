## 1. 启动流程

```mermaid
sequenceDiagram
    autonumber
    actor User as 玩家
    participant Launcher
    participant FX as JavaFX
    participant App as GobangApp
    participant View as GameView
    participant Engine as GameEngine
    participant BoardUI as BoardView
    participant Clock as Timeline

    User->>Launcher: main()
    Launcher->>FX: launch(GobangApp)
    FX->>App: start(Stage)
    App->>View: new GameView()
    View->>Engine: new GameEngine()
    View->>BoardUI: new BoardView()
    View->>View: startNewGame()
    View->>Engine: startNewGame(mode)
    Engine-->>View: 棋盘清空 / 黑方先手
    View->>BoardUI: setBoard / redraw
    View->>Clock: startCountdown(30s)
    App->>App: stage.setScene / show
    App-->>User: 显示五子棋主界面
```

## 2. 落子与胜负判定（双人 / 人机）

```mermaid
sequenceDiagram
    autonumber
    actor User as 玩家
    participant BoardUI as BoardView
    participant View as GameView
    participant Engine as GameEngine
    participant Board as Board
    participant AI as GobangAI
    participant Stats as GameStats
    participant Alert as 胜负弹窗

    User->>BoardUI: 点击交叉点
    BoardUI->>View: onCellClicked(row, col)
    View->>Engine: canPlayerPlace()
    alt 不可落子
        Engine-->>View: false
        View-->>User: 忽略点击
    else 可落子
        View->>Engine: placeStone(row, col)
        Engine->>Board: set(row, col, current)
        Engine->>Engine: findWinningLine(...)
        alt 五子连线
            Engine-->>View: status = WIN + winningLine
            View->>BoardUI: setWinningLine / redraw
            View->>Stats: recordResult(...)
            View->>Alert: show("对局结果")
            Alert-->>User: 显示胜负 + 高亮连线
        else 未结束
            Engine-->>View: 切换对手
            View->>BoardUI: redraw
            View->>View: resetCountdown()
            opt 人机模式且轮到 AI
                View->>AI: chooseMove(board, WHITE)
                AI-->>View: Move(row, col)
                View->>Engine: placeStone(...)
                View->>View: afterMove()
            end
        end
    end
```

## 3. 悔棋 / 超时判负

```mermaid
sequenceDiagram
    autonumber
    actor User as 玩家
    participant View as GameView
    participant Engine as GameEngine
    participant BoardUI as BoardView
    participant Clock as Timeline
    participant Stats as GameStats
    participant Alert as 胜负弹窗

    alt 点击悔棋
        User->>View: undoMove()
        View->>Engine: undo()
        Note over Engine: PVP 撤 1 步；PVE 撤玩家和 AI 两步
        Engine-->>View: 恢复棋盘 / 清除连线
        View->>BoardUI: syncBoardView()
        View->>Clock: resetCountdown()
    else 倒计时归零
        Clock->>View: onTick() remaining<=0
        View->>Engine: forfeitCurrentPlayer()
        Engine-->>View: 对方获胜
        View->>BoardUI: syncBoardView()
        View->>Stats: recordResult(...)
        View->>Alert: show("对局结果")
        Alert-->>User: 超时判负提示
    end
```

## 4. 人机对战（wuziqi：玩家执黑，AI 执白）

对应 `org.example.wuziqi`：`GameController` 选择 `GameMode.PVE` 后开局，玩家落子经 `canPlayerPlace` / `placeStone`，再由 `PauseTransition(350ms)` 触发 `WuziqiAI.chooseMove`。

```mermaid
sequenceDiagram
    autonumber
    actor User as 玩家
    participant Ctrl as GameController
    participant BoardUI as BoardView
    participant Engine as GameEngine
    participant Board as Board
    participant Delay as PauseTransition
    participant AI as WuziqiAI
    participant Stats as GameStats
    participant Alert as 胜负弹窗

    User->>Ctrl: 选择人机对战(PVE) 并点击「开始 / 重开」
    Ctrl->>Engine: startNewGame(PVE)
    Engine->>Board: clear()
    Engine-->>Ctrl: 黑方先手 / status=PLAYING
    Ctrl->>BoardUI: setBoard / redraw
    Ctrl-->>User: 显示空棋盘，玩家执黑、AI 执白

    User->>BoardUI: 点击交叉点
    BoardUI->>Ctrl: onBoardClicked(row, col)
    Ctrl->>Engine: canPlayerPlace()
    Engine-->>Ctrl: true（非 AI 回合）
    Ctrl->>Engine: placeStone(row, col)
    Engine->>Board: set(row, col, BLACK)
    Engine->>Engine: findWinningLine(...)
    Engine-->>Ctrl: 未五连，换手 WHITE
    Ctrl->>BoardUI: redraw
    Ctrl->>Ctrl: maybeTriggerAi()

    Ctrl->>Delay: play(350ms)
    Delay->>AI: chooseMove(board, WHITE)
    Note over AI: 1.己方成五  2.拦截玩家成五  3.启发式评分
    AI-->>Ctrl: Move(row, col)
    Ctrl->>Engine: placeStone(AI)
    Engine->>Board: set(row, col, WHITE)
    Engine->>Engine: findWinningLine(...)

    alt 形成五连或满盘
        Engine-->>Ctrl: status 终局 + winningLine
        Ctrl->>BoardUI: setWinningLine / redraw
        Ctrl->>Stats: recordResult(PVE, status)
        Ctrl->>Alert: show("对局结果")
        Alert-->>User: 你获胜 / AI获胜 / 平局
    else 未结束
        Engine-->>Ctrl: 换回 BLACK
        Ctrl->>BoardUI: redraw
        Ctrl-->>User: 等待玩家继续落子
    end
```
